# 《我与地坛》候选池：框架

## f01 地坛式自我安顿

```yaml
id: f01
title: 地坛式自我安顿
type: framework
source_chapter: 我与地坛
source_quote: "去它的老树下或荒草边或颓墙旁，去默坐，去呆想。"
summary: |
  把一个稳定、可返回的场所或实践变成自我秩序的容器。
  这个框架不是为了立刻解决问题，而是先让人从混乱中退后一步。
  使用者需要固定地点、固定时长、低干扰观察和事后记录。
tags: [self-regulation, place, reflection]
```

## f02 死亡问题后置法

```yaml
id: f02
title: 死亡问题后置法
type: framework
source_chapter: 我与地坛
source_quote: "剩下的就是怎样活的问题了。"
summary: |
  作者把最极端的存在问题从“要不要结束”转成“怎样继续活”。
  作为 skill 时，它只能用于文学化反思和低风险自我整理。
  若用户处在现实自伤危机中，必须转入安全支持，而不是继续哲学化。
tags: [existence, crisis-boundary, life-design]
```

## f03 限制内行动设计

```yaml
id: f03
title: 限制内行动设计
type: framework
source_chapter: 我与地坛 / 好运设计
source_quote: "一个人，出生了，这就不再是一个可以辩论的问题。"
summary: |
  先承认不可改写的事实，再寻找仍然可行动的一小块空间。
  它适合把身体、家庭、年龄、处境等限制转化为本周可执行的微行动。
tags: [constraint, action, acceptance]
```

## f04 写作零度启动

```yaml
id: f04
title: 写作零度启动
type: framework
source_chapter: 扶轮问路（代跋）
source_quote: "写，真是个办法，是条条绝路之后的一条路。"
summary: |
  写作不是从技巧开始，而是从生命疑难、无法安放的经验和必须说清的问题开始。
  这个框架适合启动个人写作、创作复盘和低谷中的表达。
tags: [writing, creation, meaning]
```

## f05 记忆与印象重建

```yaml
id: f05
title: 记忆与印象重建
type: framework
source_chapter: 记忆与印象1 / 记忆与印象2
source_quote: "记忆在这儿又出了差误。"
summary: |
  用地点、墙、旧物、人物和身体感受重建个人生命史。
  它不是追求准确年表，而是找到影响当下自我理解的情感线索。
tags: [memory, narrative, identity]
```
