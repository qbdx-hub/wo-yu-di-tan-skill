# 《我与地坛》候选池：原则

## p01 不把苦难做成鸡汤

```yaml
id: p01
title: 不把苦难做成鸡汤
type: principle
source_chapter: 我与地坛 / 好运设计
source_quote: "就命运而言，休论公道。"
summary: |
  谈苦难时先承认它的不公和不可替代，不急着寻找积极意义。
  只有在尊重痛苦真实重量之后，行动建议才不显得冒犯。
tags: [suffering, boundary, empathy]
```

## p02 迟到理解要提前做

```yaml
id: p02
title: 迟到理解要提前做
type: principle
source_chapter: 我与地坛 / 合欢树 / 秋天的怀念
source_quote: "不知道儿子的不幸在母亲那儿总是要加倍的。"
summary: |
  不要等到失去后才理解亲人的承担。
  在关系还存在时，主动想象对方的处境、焦虑和未说出口的愿望。
tags: [family, empathy, regret]
```

## p03 场所比道理先稳定人

```yaml
id: p03
title: 场所比道理先稳定人
type: principle
source_chapter: 我与地坛
source_quote: "那儿是可以逃避一个世界的另一个世界。"
summary: |
  人在混乱中常常不能被道理说服，却可以先被一个低干扰场所安放。
  先恢复秩序，再谈意义。
tags: [place, recovery, order]
```

## p04 写作服务于追问而非表演

```yaml
id: p04
title: 写作服务于追问而非表演
type: principle
source_chapter: 扶轮问路（代跋）
source_quote: "写作之终于的寻求，即灵魂最初的眺望。"
summary: |
  写作的起点不是证明文采，而是把心里无法绕开的疑难摆到纸面上。
  好文章先回答“我到底在追问什么”。
tags: [writing, inquiry, authenticity]
```
