# 《我与地坛》候选池：术语

| 术语 | 作者用法 | 可迁移意义 |
|---|---|---|
| 地坛 | 精神场所、自我安顿容器 | 低干扰、可返回的恢复场 |
| 死 | 确定会到来的事实 | 把终极焦虑转成今日行动边界 |
| 活 | 在限制中继续追问 | 非鸡汤式生命设计 |
| 母亲 | 另一个受苦主体 | 关系中的迟到理解 |
| 命运 | 不可替代、不可完全讲理的分配 | 承认限制，再找行动空间 |
| 苦难 | 不可美化的存在条件 | 避免把痛苦工具化 |
| 写作的零度 | 从生命疑难出发的写作起点 | 写作启动框架 |
| 好运设计 | 理想人生反事实推演 | 价值排序和缺陷检验 |
