# 《我与地坛》候选池：案例

## c01 地坛中的死亡与活法转换

```yaml
id: c01
title: 地坛中的死亡与活法转换
type: case
source_chapter: 我与地坛
source_quote: "死是一件不必急于求成的事。"
summary: |
  作者在残疾后长期进入地坛，反复想死亡和出生。
  后来问题从是否结束生命，转成如何继续活、如何写作、如何面对时间。
tags: [existence, place, transformation]
```

## c02 母亲在地坛寻找儿子

```yaml
id: c02
title: 母亲在地坛寻找儿子
type: case
source_chapter: 我与地坛
source_quote: "有过我的车辙的地方也都有过母亲的脚印。"
summary: |
  作者多年后才意识到，自己以为孤独承受痛苦时，母亲也在独自承受加倍的恐惧。

tags: [mother, empathy, regret]
```

## c03 好运设计中的缺陷检验

id: c03

type: case
source_chapter: 好运设计
